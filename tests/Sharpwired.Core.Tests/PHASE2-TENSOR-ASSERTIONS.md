Phase 1 has no compiler and no tensor evaluator. The Handwired tests below compare with the tensor evaluator or read the compiled program. Phase 1 ports their reference-evaluator part. Phase 2 adds the tensor assertion in the last column.

## Plan task 4

In this section, "tensor agreement" is Handwired `checkTensorAgreement(circuit, roots, sources)`: `validateCircuit` passes, and for `compileTensorProgram(roots, lowerGathers)` with `lowerGathers` true and false, `validateTensorProgram` passes and `evaluateTensor(source)` gives the reference value (`Object.is`) on each wire of `wireOrder`. The phase 1 tests call `ValidateCircuit` only.

"Cost" is Handwired `cost(circuit, root)`: `valueCount - sourceSize` and `layers.length` of `compileTensorProgram([root])`. Phase 1 has no compiler. `ComparisonTests.Cost` counts the operations that the root reads, by the `findLiveOperations` rule without gather plans, and counts one layer for each depth of these operations. This count needs the dead-operation removal of the compiler, for example the score that the atom of a strict rounding stage copies in is not counted. Phase 2 adds the same assertions with `compileTensorProgram([root])`.
