# Phase 3 timing assertions

Phase 1 ports the float64 spring matrix functions of Handwired `src/runtime/host-timing.ts` (`SpringMatrix.cs`) and the spring macros (`Macros.Spring.cs`). Phase 1 does not port the frame planning: `advanceFrame`, `quantizeTimeMs`, `quantizeFrameTiming`, `countSpringSteps`, `SpringClockConfig`, `validateSpringClockConfig`, `SpringClock` and `stoppedSpringClock`. Phase 3 (R3.2) ports them. The Handwired tests below need these functions. Phase 3 adds the assertions in the last column.
